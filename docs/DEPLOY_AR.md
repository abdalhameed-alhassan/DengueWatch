# نشر DengueWatch SD على GitHub + Vercel + Aiven

الفكرة نفسها المستخدمة مع SNTMP وSBDAS: **GitHub** يحفظ الشيفرة ← **Vercel** يشغّل الموقع ← **Aiven MySQL** يحفظ البيانات. الجلسات تُحفظ في جدول `sessions` بالقاعدة لأن Vercel لا يحتفظ بملفات.

## ما يميّز هذه النسخة
- صفحة الدخول فيها زر **الدخول إلى واجهة وزارة الصحة** بلا رقم هاتف أو كلمة مرور (يعمل فقط عند `DEMO_LOGIN=1`، ولحساب مدير الترصد التجريبي فقط).
- حساب العرض **للقراءة فقط**: لا يستطيع اعتماد الأطباء أو إيقافهم ولا تعديل المنشآت أو حدود التنبيهات أو حالة التنبيهات. المسموح له فقط تشغيل التنبؤ (تُحفظ آخر 10 تشغيلات).
- التنبؤ مكتوب بـ PHP (كان بايثون)، وهو ترجمة مطابقة لنموذج Ridge الأصلي (نتائجه مطابقة لبايثون تماماً في الاختبار)، فيعمل زر «تشغيل التنبؤ الآن» على Vercel. نسخة بايثون الأصلية محفوظة للمرجع في `tools/ml_reference`.
- كلمات مرور كل المستخدمين في القاعدة عشوائية غير معروفة؛ لا يدخل أحد بـ manager123 أو doctor123. لتفعيل دخول عادي لمستخدم: `tools\dengue_tools.ps1` الخيار 2.
- البيانات التجريبية مولَّدة حتى تاريخ إنشاء الملف (17 نوفمبر 2026): 18 ولاية و186 محلية و276 منشأة و548 طبيباً ونحو 23.7 ألف حالة (3 سنوات)، مع تنبيهات وتشغيل تنبؤ جاهز.
- المشروع الأصلي في `PROJICT\Dengue_ML` لم يتغير.

## الخطوات (يدوية لأنها حساباتك)
1. **قاعدة البيانات (Aiven):** استعملي خدمة MySQL نفسها المستخدمة مع SNTMP وSBDAS، فالخطة المجانية تسمح بخدمة MySQL واحدة. تُنشأ قاعدة **جديدة** باسم `dengue_ml` داخلها ولا تُمسّ القاعدتان الأخريان. شغّلي `tools\dengue_tools.ps1` واختاري **1** (يطلب Host وPort وكلمة المرور ومسار شهادة CA، ولا يحفظ شيئاً).
2. **GitHub:** أنشئي مستودعاً **خاصاً** فارغاً (بلا README) باسم `DengueWatch`، ثم شغّلي `push_to_github.ps1` وأدخلي رابطه.
3. **Vercel:** Add New ← Project ← اختاري المستودع ← Framework Preset = Other ← أضيفي المتغيرات حسب `tools\vercel_env_vars_TEMPLATE.txt` (`DB_NAME=dengue_ml`) ← Deploy.
4. افتحي الرابط واضغطي «الدخول إلى واجهة وزارة الصحة».

## متغيرات Vercel
`DB_HOST` `DB_PORT` `DB_USER` `DB_NAME=dengue_ml` `DB_PASS` (Sensitive) `DB_SSL=1` `DB_SSL_CA_PEM` `APP_BASE_URL=/` `SESSION_STORE=db` `DEMO_LOGIN=1`

## ملاحظات
- لإيقاف الدخول التجريبي: احذفي `DEMO_LOGIN` (أو اجعليه 0) ثم Redeploy، فيختفي الزر.
- خدمة Aiven المجانية قد تُطفأ عند الخمول؛ شغّليها من لوحة Aiven إن لم يفتح الموقع. وفترتها التجريبية تنتهي نحو 6 ديسمبر 2026.
- تسجيل الأطباء الجدد يعمل (يبقى الطلب «بانتظار الاعتماد»)، لكن الاعتماد يحتاج دخولاً عادياً بحساب مدير بكلمة مرور تعيّنينها بالأداة؛ حساب العرض لا يعتمد.
- لتجديد البيانات التجريبية بتاريخ أحدث: `tools/seed_demo_local.php` ثم `prepare_generated_db.php` ثم `build_database_sql.sh` على جهاز فيه MySQL.
- الاختبارات في `tests/` (تحتاج خادماً محلياً وقاعدة MySQL): `smoke_http.py` و`flows_http.py`.
